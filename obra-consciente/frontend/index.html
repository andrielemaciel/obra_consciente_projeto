Registrar movimentação

Registre entrada de compra ou saída para uso.

Seu perfil atual é Consulta. Para cadastrar materiais e registrar movimentações, promova sua conta para Responsável pelo estoque.

  1. Abra outro terminal na pasta backend. Não precisa fechar o site.
  2. Execute o comando abaixo, trocando pelo e-mail que usou no cadastro:
    npm run promover-estoquista -- seu-email@exemplo.com
  3. Depois, saia da conta no site e entre novamente. Os botões de cadastro e movimentação serão liberados.

Esse comando deve ser executado por quem administra o computador e o banco da aplicação.
